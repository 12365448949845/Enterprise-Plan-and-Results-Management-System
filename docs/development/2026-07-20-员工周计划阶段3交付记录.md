# 员工周计划阶段 3 交付记录

日期：2026-07-20

## 交付结论

阶段 3“周计划完整闭环”已完成。系统已形成月计划条目到周计划条目的强关联，并支持员工维护、直属领导审批、部门负责人审批后只读查看。

审批口径：日计划提交即执行并由直属领导点评或退回；周计划由直属领导审批；部门负责人不参与周计划二次审批。

## 数据库

- 新增 `biz_week_plan` 周计划主表。
- 新增 `biz_week_plan_item` 周计划条目表。
- 新增员工自然周唯一约束，以及状态、审批人、部门和父子关联索引。
- `00-init.sql` 支持新库初始化。
- `SchemaMigration` 使用 `CREATE TABLE IF NOT EXISTS` 支持旧库幂等升级。

## 后端

- 员工接口：列表、父级选项、详情、新建、修改、草稿删除、提交、撤回；删除仅允许草稿或已驳回计划，审计记录继续保留。
- 直属领导接口：待审批/历史列表、详情、通过、驳回。
- 部门负责人接口：已通过/已驳回列表和详情，只读且无审批写接口。
- 状态机：`DRAFT -> PENDING -> APPROVED/REJECTED`，以及 `PENDING -> DRAFT` 撤回。
- 后端校验周一至周日、历史周、父级月份交集、父级审批状态、归属员工和部门、真实直属关系及版本冲突。
- 保存、提交、撤回、删除、通过和驳回均写审计日志；提交和审批结果写入现有待办/通知表。
- 返回父级月计划名称、月份、类型、权重、任务、截止日期、既有拆解周数和下级日计划数量占位字段。

## PC Web

- 员工端：周计划列表、编辑、详情页面及导航入口。
- 直属领导端：周计划审批列表、详情抽屉及待办入口。
- 部门负责人端：审批结果只读台账，不展示待审批计划和审批按钮。
- API、路由和状态文案已统一接入。

## 环境说明

当前机器没有安装 Maven，项目也没有 Maven Wrapper，因此使用 `javac`、项目现有 `target/codex-libs` 依赖缓存和 JUnit Platform Launcher 完成等价编译与周计划测试。部署前仍建议在标准 Maven 环境执行一次 `mvn test`。
