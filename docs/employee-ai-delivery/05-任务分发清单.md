# 任务分发清单

## 使用方式
本清单可直接复制单个任务给 AI 执行。建议先执行 A 组，再并行执行 B 组，最后执行 C 组和 D 组。

## A1 员工端 API 与 Mock 中心
请在 `代码/planning-platform/web-admin` 中完成员工端 API 中心改造。

要求：
1. 扩展 `src/api/employee.ts`。
2. 增加员工端全部页面需要的类型定义。
3. 增加 mock 数据和回退逻辑。
4. 暴露统一 API 函数。
5. 保持现有 Axios 封装方式。
6. 不修改无关 API 文件。

验收：
- 所有员工端页面都有对应 API 函数。
- 请求失败时可回退 mock 数据。
- 字段名与 SDD 一致。

## A2 员工端路由补齐
请在 `代码/planning-platform/web-admin` 中补齐员工端路由。

要求：
1. 修改 `src/router/index.ts`。
2. 增加员工工作台、月计划详情、月计划编辑、日计划编制、成果提交、绩效依据、申诉记录路由。
3. 保持登录拦截逻辑。
4. 不修改无关模块路由。

验收：
- 所有员工端页面路由可访问。
- 未登录时仍会跳到 `/login`。

## B1 员工工作台
请开发员工工作台页面增强版。

要求：
1. 基于现有 `src/views/employee/EmployeeDashboard.vue` 修改。
2. 接入员工端 dashboard API。
3. 展示月计划列表、日计划日历、汇总卡片、绩效依据入口、申诉记录入口。
4. 页面不能为空白。
5. 状态标签展示要正确。

验收：
- 月计划和日历可见。
- 入口可点击。
- mock 数据下可演示。

## B2 月计划详情页

验收：
- 详情信息完整。
- 时间轴展示正常。
- 编辑按钮按状态显示。

## D1 联调与互验
请完成员工端与领导端计划流转联调。

要求：
1. 校验草稿、提交、通过、驳回、再次提交链路。
2. 校验工作台、详情页、编辑页状态一致。
3. 校验确认记录时间轴可追踪。

验收：
- 员工与领导状态同步。
- 驳回后可重新编辑并提交。
- 关键流转均有记录。
