# 若依到自研底座迁移清单

版本：v0.1  
日期：2026-07-10

## 1. 迁移目标

将成果计划系统从若依二开路线迁移到自研底座 `planning-platform`，保留已有业务分析成果，剥离若依的禁用模块、无关业务和商业开关。

## 2. 保留资产

| 资产 | 路径 | 迁移方式 |
| --- | --- | --- |
| 需求文档 | `docx/3-需求文档/成果计划系统需求文档.md` | 作为主需求来源 |
| 数据库设计 | `docx/5-数据库设计文档/数据库设计文档.md` | 转为自研 DDL |
| 接口设计 | `docx/6-接口设计文档/接口设计文档.md` | 转为自研 Controller/API |
| 权限矩阵 | `docx/7-权限矩阵文档/权限矩阵文档.md` | 转为角色、菜单、按钮、数据权限 |
| AI 开发清单 | `docx/12-AI开发清单/AI开发清单.md` | 第二阶段参考 |
| 若依 planning 模块 | `代码/ruoyi-vue-pro/yudao-module-planning` | 仅参考业务状态和接口，不直接绑定 |
| 若依 PC 工作台 | `代码/ruoyi-vue-pro/yudao-ui/yudao-ui-admin-vue3/src/views/planning` | 参考页面结构 |
| 若依 uni-app 页面 | `代码/ruoyi-vue-pro/yudao-ui/yudao-ui-admin-uniapp/src/pages-planning` | 参考移动端轻操作 |

## 3. 不迁移资产

| 对象 | 原因 |
| --- | --- |
| 若依 AI 模块 | 存在禁用/商业引导，不符合自研可控目标 |
| 若依商城、CRM、ERP、IoT、IM 等模块 | 与成果计划首版无关 |
| 若依动态租户复杂能力 | 当前按中小企业单公司优先，后续再扩 |
| 若依代码生成器整套链路 | 首版不做低代码，避免拖慢核心业务 |

## 8. 停止条件

若以下任一条件发生，应暂停自研底座并重新评审：

1. 2 周内登录、用户、组织、权限仍无法跑通。
2. 数据权限无法在后端统一校验。
3. 移动端无法复用同一套业务接口。
4. 首版开发量明显超过直接购买成熟商业产品的成本。
